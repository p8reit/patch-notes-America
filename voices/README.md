# Chatterbox voice references

Place clean reference recordings in this directory as mono or stereo WAV files.
Use the filename (without `.wav`) as the host's **Chatterbox voice ID**. For
example, `wade.wav` is selected with the voice ID `wade`.

Use recordings you own or have permission to use. A short, clean clip without
music, background noise, or overlapping speakers produces the best result.
The special voice ID `default` uses Chatterbox's built-in voice and needs no
file.
